About Configurations

A configuration maps rules to fields in a data table. You must create one before processing any data through Datavant Connect.

Use configurations for:

  • Tokenization — de-identify and tokenize input data
  • Data onboarding — load data into Datavant Connect
  • Both — tokenize and onboard in one step
