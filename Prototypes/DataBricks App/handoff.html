Alert
intent: default | success | warning | error
variant: contained | notContained
 In dart-v0 this was: neutral / info / positive / caution / negative. Main branch uses intent="default" for blue info-style alerts.
TextInput
label: string
description: hint text above input
required: boolean — renders red asterisk
error: string — validation message
 Hint text is the description prop, not a separate Label component. Order: label → description → input → error.

 Native component in main branch — no custom implementation needed. Completed + active = dv-blue-600 fill.
